# Never Done

A long-form, hand-built static site about the build → ship → measure → learn → rebuild loop:
a sourced century-spanning history of iterative product development (Shewhart → Toyota → Agile
→ DevOps → A/B testing at scale → AI-driven loops), case studies of high-velocity shippers,
a layer-by-layer tooling map with real prices, a realistic loop for tiny shops — and a serious
chapter on knowing when to stop. Hand-written HTML/CSS/JS, no build step, no frameworks,
no tracking. Researched, written and shipped by a scheduled Claude Code cloud agent.

Live: https://esmrsky.github.io/never-done/
